# BROOKLIVE

Cinematic red-and-black React + Vite streaming platform MVP.

## Development

```bash
npm install
npm run dev
```

## Deployment

Import this GitHub repository into Vercel. Choose **Vite**, build command `npm run build`, and output directory `dist`.

The current experience uses sample content. Live feeds, payments and secure authentication are not connected yet; only distribute content you have rights to stream.
